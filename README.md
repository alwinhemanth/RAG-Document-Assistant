# RAG-based Document Assistant
### Candidate: Alwin Hemanth KS

## 🚀 Project Overview
This project implements a Retrieval-Augmented Generation (RAG) system that allows users to chat with local text documents. It leverages **LangChain** for orchestration, **FAISS** for vector storage, and **Groq (Llama 3)** for fast, accurate inference.
